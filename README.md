# Cisco Packet Tracer: Small Office DHCP Configuration

## Project Objective
This lab demonstrates how to configure a Cisco router as a DHCP server to automatically assign IP addresses to end devices within a local area network (LAN).

## Network Topology
- **Router:** Cisco 4331 (Default Gateway: 192.168.1.1)
- **Switch:** Cisco 2960
- **Hosts:** 2 PCs configured for DHCP

## Core Configurations Implemented
- IP addressing on Router Gigabit interfaces.
- DHCP Pool creation (`OfficePool`) with defined network scope and default router.
- Verified successful IP allocation on end devices using DHCP.

## How to Run This Lab
1. Download and install [Cisco Packet Tracer](https://netacad.com).
2. Download the `small_office_dhcp.pkt` file from this repository.
3. Open the file in Packet Tracer to view the active running configurations.
